## 1. Conventions as landed

### 1.1 Out-of-sample shadow evidence (ratified, re-grounded)

The birth transition is excluded from candidate evidence because the patch
was fitted on it (**train/test separation**), not because the store cannot
carry it. Both numbers are now reported on every run and every candidate:

| number | definition |
| --- | --- |
| `primary` | ratio-of-means over flipped, out-of-sample, shadow-scored ticks |
| `secondary_mean_of_ratios` | the same ticks, mean of per-tick ratios |
| `with_in_sample` | the primary set plus the birth-tick sample |

The with-in-sample sample is computed at birth on the shadow copy, stored as
`CandidateRecord.in_sample`, never in `evidence`, never read by `#23`/`#22`,
and never read by the gain floor.

**Measured:** the training transition is systematically optimistic. On the
registered trace the out-of-sample ratio is **1.013378** (fails) while the
birth-sample-inclusive ratio is **0.892135** (would pass); on the historical
Round-11 trace, **0.999225** vs **0.899061**. The convention is therefore
verdict-determining here, and the "both numbers" rule is not cosmetic.

### 1.2 Aggregation — ratio-of-means primary

`R = Σ adapted / Σ base` over the declared tick set is the gate and the
metric; `mean(adapted/base)` is a labelled diagnostic. `qualified` already
used the ratio of means, so the gate and the metric are now one convention.

## 2. MDL gain floor (new binding condition)

`κ·H·dbar > 32·K`, strict, with `κ = 934.7982054975386` bits per
(latent²·tick) = `d/(2σ²ln2)`, `d = 64`, `σ² = 0.04938631785656374` (the
phase-3 in-distribution mean surprise — the variance the model's own code
assumes), `H = 20` (`POST_FLIP`), `dbar` = mean per-tick `base − adapted`
over out-of-sample evidence, `K` = stored parameters. **Ratified by the user
on 2026-11-20, before the measurement runs** (`docs/round12a-prereg.md`
§3.5).

**Units.** `surprise` is a *mean squared* latent error, not a distance. The
Gaussian code-length difference gives the exchange constant exactly as
above; the derivation is in `docs/round12a-prereg.md` §3.2–3.3 and in the
`organ.py` docstring.

**Retroactive falsifier (prereg §3.5), refused.** The Round-11 t27
candidate, reproduced under the historical `trigger="round11"` diagnostic:

| quantity | value |
| --- | --- |
| K | 5,056 (rank 26) |
| dbar | 1.897225156e-4 |
| gain at H=20 | **3.547045343304427 bits** |
| cost 32K | **161,792.0 bits** |
| verdict | `admitted=False`, `uneconomic`, short by **4.56e4×** |

Break-even horizon for that gain: ~9.1e5 ticks. The prereg's worked example
(4.14 bits, using the recorded post-flip mean as the base scale) and the
measured 3.55 bits differ only because the trace's own per-tick mean base is
0.2447, not 0.28597 — same order, same verdict.

The floor refuses every candidate measured this round:

Refusal classes are distinguished: `harmful` (`dbar <= 0`) vs `uneconomic`

size by changing κ or H by 3–5 orders of magnitude; that is a pre-registration
question for a future round, not a tuning knob.

## 3. Trigger — evidence sufficiency

`N_MIN = 2` replaces `tick >= fit_window`. The fit window and the capacity
bound use the actual `N = min(fit_window, tick)`. `N_MIN = 2` is the
smallest evidence with one transition to fit and one out-of-sample
transition to test.

**Measured consequence (pre-registered after the derivation, before the
runs):** seed 7's registered birth moves **t19 → t12** (its first spike),
`N = 12`, rank 19, **K = 3,712**; seed 0 births at **t9** (its first spike),
`N = 9`, rank 14, **K = 2,752** (small, and smaller than seed 7's).

That move is not cosmetic: it changes the registered verdict. The Round-11
trace was produced by a guard that skipped the onset spike; with evidence
sufficiency the candidate is born at the onset and its evidence covers the
whole flipped phase plus recovery.

the live half fires on the **control** seed, not the registered one. That is

## 6. Findings

1. **The trigger change reverses the Round-11 verdict.** Round 11's knife-edge
   0.999225 pass was produced by the arbitrary guard selecting a late window
   (birth t19). With evidence sufficiency the candidate is born at the onset
   and is **harmful** in the flipped phase (primary 1.0134, residence
   1.0608); it never qualifies pre-floor. The registered ADAPTATION gate
   **FAILS**. This is the round's primary finding, and it supersedes the
   Round-11 pass as a statement about the registered trace.
2. **The out-of-sample convention is verdict-determining.** The birth sample
   (the single training transition) is strongly optimistic: including it
   flips both traces (1.0134 → 0.8921; 1.0321 → 0.9601). The ruling was made
   on principle (train/test separation); the measurement shows the principle
   has teeth.
3. **The gain floor refuses everything, as pre-registered.** The Round-11
   promotion is refused by 4.56e4×; seed 0's pre-floor pass by 524×; the
   organ probe's by 2,154×. Break-even horizons are 10^4–10^6 ticks. The
   honest state is: the protection works and the learning is not earning its
   description cost.
4. **The gate discriminates on the one trace where it promoted.** Seed 0's
   real candidate qualified at 0.9832 while three null constructions never
   qualified over 27 ticks (zero exactly 1.0; random 1.0456; shuffled
   1.1263). Post-hoc, but it is the direct test of "is the pass noise?" — the
   answer is no, and the margin is thin (5 ticks).
5. **The seed-7 null suite is uninformative by construction.** The real
   fitted candidate is harmful there, so real = nulls = 0 promotions even
   ablated. The stop condition "if any null promotes, the seed-7 pass has no
   content" does not fire, but neither does it measure anything on that
   trace. The pre-registered placement of the nulls was wrong for the trace
   the round actually produced; the post-hoc seed-0 probe fixes the placement
   at the cost of pre-registration.
6. **ADAPTATION's tick set depends on the floor it measures.** A refused
   candidate keeps being shadow-scored: seed 0's flipped set is 18 ticks
   (1.0321) with the floor on and 5 ticks (0.9832) ablated, because the
   ablated run promoted (and pruned) the candidate at t14. Both are reported;
   neither is tuned. For 12b this needs a fixed-evidence-window convention or
   a per-candidate metric; the trace-level gate is not invariant to the gate
   it measures. **Open convention issue, recorded.**
7. **The live half fires on the control seed, not the registered one.**
   Seed 0 reaches `#21→#24→#25→evict` (two motif ids, `ovr-02` t11–14,
   `ovr-03` t20–27, stale/evict); seed 7 has 0 motif cohorts. The derived
   thresholds are reachable on a real trace, but on the trace where the
   nursery candidate also passes pre-floor. 12b's repeated-flip scenario is
   still needed to measure the live half on a persistent trace.
8. **The 16-stream probe's end state is no longer empty.** With (2,2) the
   probe produces 39 motif cohorts (from 0), and the final tick adopts an
   overlay that is legitimately resident at the end. The old
   `test_end_state_is_clean` was **re-pinned** to the measured end state, not
   weakened; the registered seed-7 end state also has a resident (refused)
   candidate with 14,848 patch bytes. "Clean end state" is no longer a
   property of a refused-everything run.
9. **`INV-PROMOTE-ONCE`'s D3 half is unwired.** `DebrisPool.promote` has no
   executor caller, so the issuance account's `promoted` term is structurally
   0 in every run (measured 0 of 4,000). The nursery `#22` promotion is the
   live one. Recorded; not fixed this round.
10. **The criterion-M off-by-one is disclosed, not hidden.** The implemented
    streak rule is stricter than the pre-registered reading (0.6718 % vs
    0.9784 %); the pair and the criterion are unchanged.
11. **A real reporting bug was found and fixed** during the wave:
    `candidate_fit.record` was capturing `fit_history[-1]` (a later
    live-overlay fit) instead of the candidate's own birth fit; on seed 0
    that reported K=3,712 for a 2,752-parameter candidate and would have
    corrupted the falsifier arithmetic.
